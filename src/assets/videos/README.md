# Project demo videos

Drop a screen recording here named exactly as below and it appears on that project's entry automatically (the page shows a "Demo video coming soon" placeholder until then). No code changes are needed.

- Format: `.mp4` (H.264 video, AAC audio plays everywhere).
- File names are case-sensitive.
- GitHub rejects any single file over **100 MB** (and warns above 50 MB), so keep each video well under that. Aim for 1080p or 720p, 30 fps, a minute or two long; compress with HandBrake or `ffmpeg -i in.mov -vcodec libx264 -crf 28 -preset slow -acodec aac out.mp4` if needed.
